Ground mobility · Turning

Thrust-assisted turning

Upward rotor thrust partially unloads the wheels and reduces lateral scrub forces. The approach reduced turning radius by 78.17% in the evaluated case.

VIDEO

Add assets/videos/slope-control.mp4

Ground mobility · Incline

Rotor-assisted incline control

Distance measurements estimate the robot's angle relative to the slope, enabling rotor assistance when wheel traction alone becomes insufficient.

VIDEO

Add assets/videos/height-assist-control.mp4

Flight control · Vertical

Height-assist control

Added closed-loop vertical control around a height reference to reduce the need for continuous manual vertical-thrust adjustment.

Personal project · MATLAB / Simulink

PPO-based individual rotor control

Developed a PPO policy with four continuous outputs so the network could command each rotor independently rather than relying on a conventional rotor mixer.

  • Four continuous actions, one per rotor
  • MATLAB Reinforcement Learning Toolbox
  • Reward shaping for tracking, energy use and episode time

Physical control project

IMU feedback control of a BLDC test rig

Built a closed-loop angle-control system on a physical BLDC test rig using an ESP32, IMU feedback, Kalman-filtered angle estimation and PID control.

  • IMU-based closed-loop angle feedback
  • ESP32 controller with DShot ESC commands
  • Kalman-filtered state estimation
  • Tracking across multiple commanded angle setpoints
