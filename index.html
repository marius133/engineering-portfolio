Simulation study · Turning

Thrust-assisted turning

Total upward rotor thrust is commanded as a percentage of the vehicle's own weight. By partially unloading the wheels, the rotor thrust reduces the normal force and therefore the lateral friction forces that oppose differential-drive turning. This reduces lateral wheel scrubbing and allows the robot to follow a tighter commanded trajectory. In the simulation, a target turning radius of 0.375 m is achieved with rotor thrust corresponding to approximately 80% of the vehicle weight, reducing the turning radius by 78.17% compared with the unassisted case.

Simulation study · Slope control

Rotor-assisted slope control

Two distance sensors mounted a known distance apart measure the distance from the robot to the slope independently. The difference between the two measurements is used together with the known sensor spacing to estimate the robot's angle relative to the slope. This relative-angle estimate is fed back to the controller, which regulates rotor assistance and vehicle attitude to maintain or increase useful wheel loading and improve traction on steep inclines.

Simulation study · Vertical control

Height-assist control

Closed-loop vertical control is added to the flight-control system to regulate height around a commanded reference. The simulation compares raw flight mode with height-assist mode, showing how feedback can reduce the need for continuous manual vertical-thrust adjustment.

Physical control project

IMU feedback control of a BLDC test rig

Built a closed-loop angle-control system on a physical BLDC test rig using an ESP32, IMU feedback, Kalman-filtered angle estimation and PID control. The controller supports multiple angle setpoints and continuously adjusts motor output based on the measured angular error.

  • Closed feedback loop using IMU-based angle measurements
  • ESP32-based controller with ESC commands sent using the DShot protocol
  • Kalman filtering for angle estimation and noise reduction
  • Tracking tests across multiple commanded angle setpoints

Robot actuator · Mechanical development

27:1 cycloidal robot actuator

Designed and built a compact robotic joint actuator around a 27:1 cycloidal reduction stage, integrating the stepper motor, gearbox, output hub and custom housing into a single assembly. The reduction provides approximately 12.7 Nm of output torque while retaining a compact coaxial form factor suited to robotic-arm joints. The project covered CAD design, mechanical integration, fabrication, assembly and iterative prototyping of the complete actuator.
