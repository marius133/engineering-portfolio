# Marius Halaas — Project Portfolio

Static engineering portfolio for GitHub Pages.

Repository:

`marius133/engineering-portfolio`

With GitHub Pages enabled from the `main` branch, the site URL will be:

`https://marius133.github.io/engineering-portfolio/`

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.

The site uses only HTML, CSS and JavaScript. No build step is required.

## Add project videos

Place your compressed MP4 clips here:

- `assets/videos/hybrid-robot.mp4`
- `assets/videos/simscape-model.mp4`
- `assets/videos/slope-control.mp4`
- `assets/videos/thrust-assisted-turning.mp4`
- `assets/videos/height-assist-control.mp4`
- `assets/videos/rl-path-planning.mp4`
- `assets/videos/bldc-imu-rig.mp4`

The page automatically hides the placeholder when the corresponding video loads.

### Video recommendation

- 10–25 seconds
- 720p or 1080p
- H.264 video in an `.mp4` container
- muted footage is fine if the engineering result is visually obvious
- aim for a few MB per clip when practical

Before publishing, check project wording, dates, research status, links, and any contact details you want to make public.
